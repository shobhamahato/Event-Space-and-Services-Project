# Event Space and Services

**Event Space and Services** is a web-based event management platform designed to help users discover and manage event-related services such as venues, decorators, photographers, DJs, and other event vendors.

## Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* MySQL
* Bootstrap

## Features

* User registration and login
* Event and venue browsing
* Vendor/service browsing
* Photographer services
* Decoration services
* DJ services
* Venue services
* Vendor/service selection
* Cart functionality
* MySQL database integration

## How to Run

### Requirements

* XAMPP
* PHP
* MySQL
* Web browser

### Installation

1. Clone this repository.
2. Copy the project into the XAMPP `htdocs` folder.
3. Start **Apache** and **MySQL** from XAMPP.
4. Open `phpMyAdmin`.
5. Create the required database.
6. Import the project's `.sql` database file.
7. Update the database connection settings if required.
8. Open the following URL in your browser:

```text
http://localhost/EventProject_Original/
```

## Project Purpose

The project provides a centralized platform for users to explore event spaces and related services, making event planning more convenient and organized.
